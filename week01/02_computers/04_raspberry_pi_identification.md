| Component | Function |
|-----------|----------|
| SoC |A System on Chip (SoC) integrates the CPU, GPU, memory controller, and other essential components into a single chip. It processes data, runs applications, and manages communication between hardware parts, enabling compact, energy-efficient, and high-performance devices like smartphones, tablets, and Raspberry Pi systems. |
| GPIO |GPIO (General Purpose Input/Output) pins on a Raspberry Pi allow it to interact with external electronic components. They can be programmed as input to read signals from sensors or as output to control devices like LEDs, motors, and switches. This makes them essential for robotics, automation, and electronics projects. |
| USB |USB (Universal Serial Bus) ports allow a computer or Raspberry Pi to connect and communicate with external devices such as keyboards, mice, storage drives, cameras, and printers. They also provide power and enable fast data transfer between devices. |
| HDMI |HDMI (High-Definition Multimedia Interface) transmits high-quality digital video and audio from a device to a display such as a monitor or TV. It allows a Raspberry Pi to connect to screens for displaying its interface, media, or project output clearly and in high resolution. |
| Power |Power supplies electrical energy to a device, converting it into usable voltage and current for internal components. In a Raspberry Pi, it ensures stable operation by providing consistent low-voltage DC power through USB or GPIO power inputs, allowing all parts to function correctly without damage. |
| microSD |A microSD card provides storage for operating systems, files, and applications. In a Raspberry Pi, it acts as the main storage device, holding the OS and user data, since most models do not have built-in hard drives or SSDs. |
| Network |Networking allows a device to connect and communicate with other devices and the internet. On a Raspberry Pi, it is used for web access, file sharing, remote control, and IoT projects through Wi-Fi, Ethernet, or Bluetooth connections. |
| Wireless |Wireless refers to communication without physical cables, using signals like Wi-Fi or Bluetooth. On a Raspberry Pi, it enables internet access, device pairing, remote control, and data transfer, making projects more flexible and easier to set up without wired connections. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Many components are integrated into a single board in embedded computers like the Raspberry Pi to make the system compact, efficient, and cost-effective. Combining the CPU, RAM, storage interfaces, and connectivity features reduces the need for separate hardware parts, lowering production costs and power consumption. This integration also improves reliability by minimizing wiring and potential hardware failures. It allows devices to be smaller, portable, and easier to design for specific tasks. Additionally, a single-board design simplifies setup for users, making it ideal for education, prototyping, IoT systems, and embedded applications where space and energy efficiency are important.
