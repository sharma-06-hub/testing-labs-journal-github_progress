# Part 5 – Final Reflection
Write **200–300 words** describing your learning experience during this lab.
Consider:
* What surprised you about computer hardware?
* What components were new to you?
* What challenges did you face?
* What did you learn about embedded systems?
--- Learning about computer hardware was interesting because I found out how many parts work together inside a computer. I was surprised that small components like the motherboard and CPU are so important. The CPU works like the brain, and RAM helps the computer run programs quickly while they are in use.

Some new things I learned were GPIO pins and the System on Chip (SoC) in the Raspberry Pi. GPIO pins are special because they let you connect and control external devices like lights and sensors. The SoC is also interesting because it combines many parts like the processor and graphics into one chip, making the system small and powerful.

At first, I found it hard to understand how all the parts work together. I also got confused between RAM and storage because both store data but in different ways. It took practice to remember what each part does.

From learning about embedded systems, I understand that they are designed for specific jobs like controlling machines or running simple devices. They are small, fast, and use less power. The Raspberry Pi is a good example because it can be used for projects like robots and smart devices. I also learned that embedded systems are simple but very useful because they combine many parts into one small board.
