| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |The CPU is the brain of the computer. It processes instructions, performs calculations, and controls other components. It follows fetch, decode, and execute steps to run programs efficiently. |Key CPU specifications include clock speed (GHz), number of cores and threads, cache size (L1, L2, L3), architecture (e.g., 64-bit), thermal design power (TDP), and supported socket type for motherboard compatibility. |
| RAM |RAM (Random Access Memory) temporarily stores data and instructions that the CPU needs while running programs. It allows quick access to active information, helping the computer perform tasks faster and multitask efficiently. However, its data is temporary and is lost when the computer is turned off. |Key RAM specifications include capacity (GB), speed (MHz or MT/s), latency (CAS latency), type (DDR3, DDR4, DDR5), form factor (DIMM or SO-DIMM), and bandwidth, which together determine performance and compatibility with the system. |
| Storage |Storage is used to permanently save data, files, and programs on a computer. It retains information even when the power is off. Common storage devices include hard drives (HDD), solid-state drives (SSD), and external drives, allowing users to store, retrieve, and manage data whenever needed. |Key storage specifications include capacity (GB or TB), speed (read/write performance), type (HDD or SSD), interface (SATA, NVMe, or PCIe), form factor (2.5", M.2), and durability or lifespan, which affect performance and reliability. |
| Motherboard |The motherboard is the main circuit board of a computer that connects and allows communication between all components such as the CPU, RAM, storage, and peripherals. It distributes power, manages data flow, and ensures all hardware parts work together efficiently as a single system. |Key motherboard specifications include chipset type, socket type (CPU compatibility), RAM slots and supported memory type/speed, expansion slots (PCIe), storage interfaces (SATA, M.2), form factor (ATX, microATX, mini-ITX), and connectivity options like USB and networking ports. |
| Power Supply |Converts electricity from a wall outlet into usable, low-voltage DC power and distributes it to all computer components, ensuring stable and safe operation while protecting hardware from power fluctuations and overloads. |Power output (wattage), efficiency rating (80 PLUS Bronze, Silver, Gold, etc.), form factor (ATX, SFX), number and type of connectors (CPU, GPU, SATA), modular or non-modular design, and protection features such as over-voltage, under-voltage, and short-circuit protection. |
| Cooling |Cooling system removes excess heat from computer components like the CPU and GPU to prevent overheating. It maintains optimal temperature using fans, heat sinks, or liquid cooling, ensuring stable performance, longer hardware lifespan, and preventing system damage or slowdowns. |Cooling system specifications include cooling type (air or liquid), fan size and speed (RPM), airflow (CFM), noise level (dB), radiator size (for liquid cooling), number of fans, compatibility with CPU socket, and thermal performance rating. |
