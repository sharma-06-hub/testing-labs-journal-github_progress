# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Hardware refers to the physical components of a computer or electronic system that you can touch. It includes devices such as the processor, memory, hard drive, motherboard, keyboard, monitor, and printer. Hardware works with software to perform tasks, process data, and execute instructions efficiently and enable users to accomplish goals.

## Explain Software
Write **at least 50 words** explaining what software is.
------Software is a collection of programs, instructions, and data that tell a computer how to perform specific tasks. It includes operating systems, applications, and utilities. Software enables users to create documents, browse the internet, manage data, and control hardware, making computers useful, functional, and efficient for everyday activities.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
---Hardware and software interact by working together to perform tasks. Software provides instructions that tell the hardware what to do, while hardware executes those instructions. For example, when you type on a keyboard, software processes the input and directs the processor, memory, and display to produce the desired output.
